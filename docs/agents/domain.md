# Domain docs

Este es un repositorio single-context.

Antes de explorar un cambio de dominio, leer `CONTEXT.md` si existe y los ADR relevantes en `docs/adr/`. Usar el vocabulario definido allí en tickets, pruebas y documentación.

Si una propuesta contradice un ADR existente, señalar el conflicto en vez de ignorarlo. La skill de domain modeling crea o actualiza `CONTEXT.md` cuando se necesite ampliar el glosario.
