# Triage labels

| Rol canónico | Etiqueta | Uso |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Requiere evaluación de mantenimiento |
| `needs-info` | `needs-info` | Falta información del reporte |
| `ready-for-agent` | `ready-for-agent` | Está listo para implementación autónoma |
| `ready-for-human` | `ready-for-human` | Requiere intervención humana |
| `wontfix` | `wontfix` | No se realizará |

Las skills deben aplicar estas etiquetas cuando mencionen el rol correspondiente.
