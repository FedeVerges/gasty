# Glosario de dominio

## Transacción

Un ingreso o gasto registrado en una fecha. Cada transacción se puede editar o eliminar de forma independiente.

## Regla recurrente

Configuración que programa transacciones mensuales futuras. Se administra desde Ajustes y no es una transacción.

## Transacción pendiente

Transacción generada por una regla con fecha dentro del mes actual o de un mes posterior. Los cambios de una regla se aplican a estas transacciones.

## Historial

Transacciones de meses anteriores. Las modificaciones o eliminaciones de una regla recurrente no lo alteran.

## Sugerencia del parser

Tipo y categoría que el parser infiere a partir del texto del usuario. Es una propuesta editable antes de guardar.

## Categoría válida

Categoría compatible con el tipo de una transacción. Al pasar de gasto a ingreso o viceversa, la aplicación reemplaza la categoría elegida por una válida.

## Chip rápido

Acceso de carga basado en el historial completo. Muestra una descripción y el último monto registrado para ella, y completa la previsualización sin guardar automáticamente.
